
# Data Documentation

## Dataset

This project uses the RadarCommDataset for radar and communication signal analysis.

## Source

Dataset repository:
https://github.com/ANDROComputationalSolutions/RadarCommDataset

## Data Format

The original dataset is provided in HDF5 format (`.hdf5`).

Python library used to read the dataset:
- h5py

## Directory Structure

- `raw/`: Original downloaded dataset files.
- `processed/`: Data generated during preprocessing and analysis.

## Data Availability

Raw and processed dataset files are not tracked by Git.

Users must obtain the original dataset from its official source and place it in the appropriate directory.

## Notes

Dataset license and attribution requirements must be reviewed before redistribution or publication of derived data.
